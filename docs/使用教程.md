# 使用教程

这份说明按「一个人在自己电脑上做漫剧」来写。软件不带模型账号，生成花的钱是你自己的接口在扣。

## 1. 安装 Python

1. 打开 https://www.python.org/downloads/ 下载 Python 3.10 或更新的版本。
2. 安装窗口最下面勾上 **Add python.exe to PATH**，再点安装。
3. 装完打开命令行，输入 `python --version`，能看到版本号就行。

## 2. 启动

把项目文件夹放在一个路径不太深的地方，例如 `D:\canvas`。

**Windows（推荐）**

双击 `start.bat`。

- 第一次会创建 `.venv` 并安装依赖，需要等一会儿，期间要能上网。
- 会弹出两个窗口：任务服务（8089）和画布（10027）。两个都不要关。
- 如果弹出防火墙确认，点允许。取消也能在本机用，只是别的电脑连不进来。

浏览器地址：http://127.0.0.1:10027

**命令行**

在项目目录里：

```bash
python -m venv .venv
```

Windows 激活：

```bash
.venv\Scripts\activate
pip install -r requirements.txt
```

macOS / Linux 激活：

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

然后开两个终端，都先激活 `.venv`：

```bash
python -m backend.run_worker
python run.py
```

只跑 `python run.py`、不跑任务服务时，画布能打开，生成不会执行。

## 3. 填自己的模型

右上角头像打开设置，找到 **MyApi 自定义渠道**。

上面有这些页签：图片、视频、文本、语音、视觉、智能体、火山引擎。

自己的中转接口：

1. 选对应页签，点 **添加模型**。
2. 按那个中转站给你的文档，填地址、模型名和 Key。
3. 保存。Key 只写在你这台电脑的 `data/` 里。

火山引擎：

1. 打开 **火山引擎** 页签。
2. 图、视频、文本用方舟控制台的 API Key。
3. 语音如果和方舟不是同一把 Key，再填语音 Key。
4. 打开你要用的类型开关。需要的话点「设为默认」，新建节点会优先走火山。

并发数字在同一页上面。一个人做漫剧，2 就够用。开太大容易把接口打满，也更容易扣费。

## 4. 在画布上做一条漫剧

1. 点底部 **+**，或在空白处右键，添加节点。
2. 常用的有：文本、图片生成、视频生成、音频引用、音色文本。
3. 从一个节点的输出拖到下一个节点的输入，连上线。生成进行时，连线会有传输动画，可以在菜单里关掉。
4. 文本节点写分镜或台词，连到图片节点当提示词。
5. 图片连到视频节点，当参考图。
6. 在节点上点生成。右上角「线程」数字是当前并发，点进去也能改上限。
7. 底部工具栏可以打开素材库、生成历史、节点定位。选中多个节点后，可以整理布局或下载。

画板数据在本机。换电脑或重装前，自己备份整个 `data/` 文件夹。不要把这个文件夹发给别人，里面有密钥。

## 5. 视频超分

视频节点上可以做超分。第一次使用会下载 Real-ESRGAN ncnn Vulkan，大约 45MB，需要显卡能跑 Vulkan。这个引擎是别人的开源项目，许可证是 BSD，和本项目的个人使用约定是分开的。

## 6. 同一家里的另一台电脑打开

`start.bat` 启动后，窗口里会打印局域网地址，形如 `http://192.168.x.x:10027`。

另一台电脑要和这台在同一个 Wi-Fi。如果打不开：

1. 把当前 Wi-Fi 改成专用网络（不要用公用网络）。
2. 右键 `ensure-lan-access.bat`，用管理员身份运行，放行防火墙。

画布仍然跑在你这台电脑上，别的电脑只是用浏览器打开页面。

## 7. 常见问题

**窗口一闪就关，或提示找不到 Python**

重新安装 Python，勾选 Add python.exe to PATH。或者在项目目录执行 `python -m venv .venv` 后再双击 `start.bat`。

**页面能开，点生成没反应**

看任务服务那个窗口还在不在。不在的话重新双击 `start.bat`，或单独执行 `python -m backend.run_worker`。

**提示 Key 无效或余额不足**

这是接口那边的问题。回设置里核对地址、模型名和 Key，并到中转站或火山控制台看余额。

**依赖安装失败**

确认能访问外网。公司网络有时会拦 pip。可以换手机热点试一次。
